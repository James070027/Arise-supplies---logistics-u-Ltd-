ARISE SUPPLIES SITE - GitHub Pages
1. Replace logo.png with your real logo (same name).
2. Upload ALL files in this folder to a new GitHub repository (root, not inside a subfolder).
3. Repo > Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: /(root) > Save.
4. After about 1 minute your link is https://YOUR-USERNAME.github.io/REPO-NAME/
5. Change the admin password (default Arise2026) in Admin > Password. Open Admin by tapping the logo 5 times.
6. To update prices: Admin > Settings > Download live.js, then upload it to the repo replacing the old live.js.
